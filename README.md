# amolmjoshi93.github.io

Personal portfolio of Amol Joshi. Plain HTML and CSS with no build step, served by GitHub Pages.

To preview locally, run `python3 -m http.server` in this folder.

Fonts are self-hosted under the SIL Open Font License: Fraunces, Instrument Sans, JetBrains Mono and Noto Serif Devanagari.
